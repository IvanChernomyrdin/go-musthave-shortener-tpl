# URL Shortener — сервис сокращения ссылок

## Назначение

Сервис принимает длинный URL и возвращает его короткую версию. По короткому URL пользователь может получить оригинальную ссылку и быть перенаправленным на целевой ресурс.

---

## Архитектура и ключевые решения

- **REST API** — взаимодействие через HTTP-хендлеры
- **Хранение** — in-memory (map) или PostgreSQL (выбор через конфиг)
- **Генерация коротких идентификаторов** — алгоритм Base62 для компактности
- **Конфигурация** — адрес запуска, строка подключения к БД, базовый URL задаются через env или флаги
- **Поддержка сжатия** — приём и отдача gzip-сжатых данных
- **Асинхронное удаление** — фоновая очистка удалённых записей

---

## Результат

- Получение короткой ссылки из длинного URL за один запрос
- Переход по короткой ссылке с HTTP-редиректом (301 или 307)
- Поддержка пакетного создания нескольких коротких ссылок за один запрос
- Персистентное хранение в PostgreSQL с возможностью работы без БД (in-memory)
